Sid-s_terminal is a terminal-style personal portfolio website. It gives the GitHub profile a lightweight, memorable website surface where visitors can explore projects, resume links, and contact information through an interactive command-line inspired UI.

## What It Does

- Presents a personal portfolio through a terminal-inspired interface.
- Provides a memorable static website that can be used as the GitHub profile website link.
- Demonstrates lightweight HTML/CSS/JavaScript interaction design.
- Can become the central launcher for the strongest AI/ML and product demos.

## Run Locally

Because this is a static site, you can open `index.html` directly or serve the folder locally:

```bash
python -m http.server 8080
```

Then open:

```text
http://localhost:8080
```
