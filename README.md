# Sid-s_terminal

Terminal-style personal portfolio website with resume, interactive JavaScript UI, and lightweight static deployment.

## What It Does

- Presents a personal portfolio through a terminal-inspired interface.
- Includes resume access and static front-end assets.
- Demonstrates lightweight HTML/CSS/JavaScript portfolio engineering.

## Tech

HTML, CSS, JavaScript.

## Repository Map

- `index.html` - main page.
- `script.js` - terminal-style interactions.
- `styles.css` - visual styling.
- `Resume1.pdf` - resume artifact.

## Status

Personal portfolio experiment.
