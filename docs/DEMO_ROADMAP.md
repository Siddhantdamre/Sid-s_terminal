# Demo Upgrade Roadmap

Goal: make Sid-s_terminal the memorable personal website hub for the whole GitHub profile.

## Current State

- GitHub Pages site is live.
- Static HTML/CSS/JS portfolio shell exists.
- README now frames it as the account website surface.

## Highest-Impact Improvements

| Priority | Upgrade | Recruiter value |
| --- | --- | --- |
| P0 | Add `projects` command listing the top 10 repos with demo links. | Makes the website useful immediately. |
| P0 | Add commands for `holup`, `deic`, `kathakaar`, `sonish`, and `resume`. | Lets visitors jump to flagship work quickly. |
| P1 | Add command suggestions and mobile-friendly shortcuts. | Improves usability. |
| P1 | Add contact and portfolio guide links. | Gives recruiters a clear next step. |
| P2 | Add a small theme toggle or command history polish. | Makes it feel more deliberate. |

## Suggested Demo Shape

- Keep it static and fast.
- Use JavaScript command routing to open project links.
- Add a visible help panel for non-terminal users.

## Definition Of Done

- Reviewer can type `projects` and reach every flagship demo.
- `resume` and `contact` commands are obvious.
- Site works cleanly on mobile and desktop.
